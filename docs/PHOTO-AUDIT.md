# Photo audit (2026-11-27)

All 124 library photographs that the app displayed were inspected visually in contact sheets, each next to its recipe name.

- Kept: 103. Each clearly shows the named dish.
- Hidden: 21. The photo did not clearly show the named dish (wrong dish, unidentifiable, or missing a defining part of the dish). These recipes now show the typographic cover.
- Files and attribution are unchanged in the repository. The list, with the reason for each, is in `photo-audit.js`; deleting a line restores that photo.
- A photo the user added to a recipe is always shown.

Limits: this was a visual check of the finished dish against the recipe name and main ingredients, done by eye from thumbnails. It is not a culinary expert review, and "kept" means "clearly plausible", not "verified to be this exact recipe".
