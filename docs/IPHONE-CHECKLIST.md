# iPhone test checklist (Rose and Marco)

Use Safari on each iPhone with https://marcopolo2350.github.io/re-7k2q9x/. Tick each item only after you have actually tried it, and note the iPhone model and iOS version.

Before you start: on each phone, open the app's Settings and tap **Export full backup**.

| # | Test | What should happen | Pass? |
|---|---|---|---|
| 1 | **Install:** in Safari tap Share, then **Add to Home Screen**, then open the app from the icon | Opens full screen with the Rose's EATS icon; the passcode works | |
| 2 | **Read-only check:** open the link with `?diag=1` at the end | A list of checks, all green; your data is untouched | |
| 3 | **Layout:** visit each tab: For You, Cookbook, Kitchen, Plan, Shop, Cook | Nothing cut off or overlapping; buttons are easy to tap | |
| 4 | **Cooking mode:** open a recipe and tap **Start cooking**; go through a few steps | Big text; the step's quantities shown; Back and Next work; ✓ marks done steps | |
| 5 | **Screen stays on:** in cooking mode, wait 2 minutes without touching | The top of the screen says "Screen stays on" and the screen doesn't dim. If it dims, note it. | |
| 6 | **Read-aloud:** in cooking mode tap 🔊, then "Read this step" | The step is spoken. If nothing happens, check the mute switch and note it. | |
| 7 | **Timer with the app open:** start a 1-minute timer and keep the app open | Alarm rings and repeats until you tap **Stop**; **Snooze** gives 1 more minute | |
| 8 | **Timer with the screen locked:** start a 1-minute timer, lock the phone, wait 2 minutes, unlock | **Expected limit:** it won't ring while locked. It should ring when you reopen the app. Use the Clock app or Siri for locked-screen alarms. | |
| 9 | **Offline:** turn on Airplane Mode, reopen the app, and browse, plan and use cooking mode | Everything works; only photos you saved for offline show | |
| 10 | **Updates:** after a new release, close the app fully and reopen it twice | The new version appears; favorites, plans and pantry are still there | |
| 11 | **TikTok:** on a recipe tap "Search it on TikTok" (with the TikTok app installed) | Opens the TikTok app, or TikTok in Safari if the app isn't installed | |
| 12 | **Your photo:** after cooking, add a cooking note with a photo from the camera or library | The photo appears on the recipe's "Rose's Kitchen Notes" | |
| 13 | **Backup:** Settings, then **Export full backup** | The share sheet opens; save to Files | |
| 14 | **Restore:** Settings, then **Restore from file**, choosing the saved backup | A preview of counts; after confirming, everything is the same; "Undo last import" appears | |
| 15 | **Leftovers:** Kitchen, What we have, then add a leftover marked "Not sure how it was cooled" | It shows the "can't say it's safe" warning and no recipe ideas | |

Report back: the item numbers that failed and what you saw, with screenshots if possible.
