## Household sharing (both phones)

You need both iPhones next to each other. It takes about 20 minutes. Write down anything that looks wrong, even small things.

**Before you start:** on each phone, open **Settings** in the app and tap **Export full backup**. Keep that file. If anything goes badly, it puts the phone back exactly as it was.

**Remember:** sharing is not automatic. A phone only gets the other phone's changes when it opens a file the other phone sent.

| # | Try this | You should see | OK? |
|---|---|---|---|
| S1 | **Sharing is off at first.** On both phones open **Settings** and scroll to **Household sharing** | It says sharing is off and "not automatic syncing", with **Start** and **Join** buttons | |
| S2 | **Create the household.** On Marco's phone tap **Start household sharing**, tap **Marco**, then **Create household code** | 12 words and a 4-digit **check number**. Write the words on paper. It then asks for two of them back | |
| S3 | **Join.** On Rose's phone tap **Join with a code**, tap **Rose**, type the 12 words with spaces, tap **Join** | It says "Joined" and shows a 4-digit check number | |
| S4 | **Compare the check numbers.** Look at both screens (on Marco's phone: Settings, Household sharing) | **The same 4 digits on both phones.** If they differ, a word was mistyped: on Rose's phone open Sharing settings, tap **Turn off household sharing**, and join again | |
| S5 | **First file.** On Marco's phone tap **Send my changes**, then **Create the file and share**. Pick **AirDrop**, then Rose's iPhone | Rose's phone asks to accept the file. Accept it, and choose **Save to Files** if it offers | |
| S6 | **Open it.** On Rose's phone: Settings, Household sharing, **Open a household file**. Pick the file in Files (look in Downloads or Recents) | A preview says **From Marco** and lists what will change. Tap **Open and merge**. Marco's grocery list and pantry now show on Rose's phone | |
| S7 | **Cancel is safe.** Send another file from Marco and open it on Rose's phone, but tap **Cancel** at the preview | "Nothing was changed." The lists are the same as before | |
| S8 | **Send a grocery list.** On Rose's phone add "test lemons" to the grocery list. Tap **Share grocery list**, then **As an encrypted household file**, and send it by **AirDrop** | Marco opens it (as in S6). "test lemons" appears on his list | |
| S9 | **Messages and Files.** Repeat S8, but pick **Messages**. On Marco's phone, press and hold the file in Messages, tap **Save to Files**, then open it from the app | The preview appears and it merges. A file can't be opened straight from Messages, so saving it to Files first is expected | |
| S10 | **Plain text.** Tap **Share grocery list**, then **As plain text**, and send it in Messages | A readable list arrives. It is **not encrypted** and doesn't change the other phone's list. That's expected | |
| S11 | **The same file twice.** Open the file from S8 again on Marco's phone | It says you've opened this file before, and **Nothing new**. Nothing is doubled | |
| S12 | **Eggs at the same time.** On Rose's phone: Kitchen, pantry, tap eggs, type **10** in "How much" and tap **Correct the amount**. Send a file and open it on Marco's phone so both show 10. Now, without sending anything: Rose types **3** and taps **Used**; Marco types **2** and taps **Used**. Then each sends a file and the other opens it | **Both phones show 5 eggs** (not 7 or 8) | |
| S13 | **A recipe and photo.** On Rose's phone add your own photo to a recipe. Tap **Share recipes**, open **Photos**, switch that recipe on, then share by AirDrop | On Marco's phone, after opening it: **Shared with me** shows Rose's photo. Marco's own photo for that recipe (if he has one) is unchanged | |
| S14 | **Offline.** Turn on **Airplane Mode** on one phone. Close the app fully and open it again. Look at recipes, the grocery list, and Settings, Household sharing | Everything works. Sharing doesn't need the internet. AirDrop still works in Airplane Mode if you switch Wi-Fi and Bluetooth back on | |
| S15 | **Turn sharing off.** On one phone: Settings, Household sharing, **Sharing settings**, **Turn off household sharing** | Your recipes, lists, pantry and photos are all still there. Only the items under **Shared with me** go away | |

**Please note** your iPhone model and iOS version. For any step that failed, note what you saw; a screenshot helps.

**The 12 words are private.** Don't post them, put a photo of them in a shared album, or send them along with a file. The 4-digit check number isn't secret; it only catches typing mistakes.
